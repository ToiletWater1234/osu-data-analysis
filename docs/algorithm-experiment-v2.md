## 评分规则

1. 保留谱面时间轴，DT / HT 用实际速度换算时长；切片保留跨边界完整 LN 和 Timing Points，Sunny 使用整图长度因子。
2. 原始 Pattern 匹配区间合并为集合。对同一键型重复匹配不会重复增加判定单位；不同键型可重叠，覆盖率不要求相加为 100%。LN 目标单位限定为 LN 的判定。
3. 以不重复头部音符计每个键型全图覆盖率 p，各特征独立计算，允许 20% 叠 + 60% 单乱 + 60% 面切等重叠结构，不将三项除以 140%。疑似 Vibro 不参与普通键型评级。
4. 局部难度取按目标音符数加权的 65 分位，比较整图 Sunny 难度后，限制相对修正在 -1 至 +0.5 个整级之间，再加到 Mixed 整图等级上。每五个表内子档视为一个整级，不直接乘原始星数或等级名称。
5. 覆盖扣级为 `max(0, 2 * log2(0.5 / p))`；p ≥ 50% 不扣级。Acc 扣级为 `max(0, (基准 Acc - 实际 Acc) * 100)`，即每低一个百分点扣一级，高于标准不额外提级。标准为常规 96%、4K 面条 97%、7K 面条 95%、6K 面条 96%。最终表内刻度 = 整图刻度 + 有限局部修正 - 5 × (覆盖扣级 + Acc 扣级)。低于表下限明确显示 `< 最低档`，不伪造未有的低段位表。
6. 参考权重为 `min(1,p/0.6) × min(1,目标音符数/30,有效时长/4秒) × 口径可靠度`。判定口径吻合为 1，有判定但无法完全吻合为 0.85，仅有实际 Acc 而无判定字段为 0.75。未完成、负数判定、零准确率、无实际成绩不产生评分。
7. 同图多条成绩只取最强贡献，最高五张贡献以参考权重再乘顺位权重 1 / 0.85 / 0.7 / 0.55 / 0.4，求表内刻度加权均值。按相同键数、常规 / 面条分别映射标签。单图、多图或低覆盖明确标记，所有能力显示“估计”。

上述系数是本站根据用户示例选择的试用参数，未从 Mania Tracker 照搬，也未经过局部回放精度验证。在局部相对难度相当时，Alpha / LN11 的图、96% Acc、60% 单乱和 60% 面切，可得到单乱 Alpha、面切 LN10；20% 的叠会降档且降权。该示例用于明确期望行为，不能由此声称所有玩家至少具有对应段位。

## 已知限制与验证

没有回放时局部 Acc 仍未知。低覆盖会产生较低权重和等级估计，不再仅因无法证明最坏下界而全部显示“证据不足”。局部 Sunny / Pattern 混合段仍可能受其他键型影响，不能等同正式段位测试。疑似 Vibro 为规则标记，不证明玩家使用抖动。

支持 4K / 6K / 7K，单图最多 30000 音符、15 分钟，最终最多 10 段，后台单图 45 秒超时。异常明确跳过，不暗中替换成旧模型。EZ / HR / DA、随机、变换键型、改键暂不参与试用结构分析。基础 B50、额外 PP 前 50、身份匹配和隐私规则保持原有逻辑，不增加 KV 写入。

测试覆盖用户 Alpha / LN11 / 96% / 重叠 60% 示例、低覆盖和低 Acc 的单调扣分、局部难度尖峰限制、客户端口径降权、去重、中文术语、lazer 黄彩折减、跨段 LN、时间轴和 4K / 6K / 7K 合成谱面。尚未用站长实际回放校准模型，不能把合成测试通过描述为现实精度已提升。
